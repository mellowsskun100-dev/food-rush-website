About Food Rush

Food Rush is a simple arcade game made for a class activity on AI-assisted coding. The goal is to catch as much food as you can without hitting the bombs.

How to Play

  1. Press the Play button on the Play page.
  2. Move the basket to catch the falling food: 🍕 🍔 🍟 🍩
  3. Avoid the bombs: 💣 🧨. Each one costs you a life.
  4. Catch the golden star ⭐ for +50 points.
  5. You have 3 lives. When they run out, the game is over.

Controls

  • Laptop: Left / Right arrow keys, or A / D, or move your mouse
  • Phone: Drag your finger across the game

Scoring

  • Each food: 10 points
  • Every 5 foods in a row adds +1 to your multiplier
  • Level goes up every 100 points, and the game gets faster

Tools Used

  • HTML, CSS, and JavaScript
  • AI-assisted coding (Claude)
  • VS Code
  • Git and GitHub
  • Vercel (hosting)
